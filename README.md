# Quantum Circuit Builder

A web app where users type a quantum algorithm in plain English and the app draws the matching quantum circuit. Built with React, TypeScript, and Vite.

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Features (Phase 1)
- Text input for quantum algorithm descriptions
- Support for Grover's algorithm (3 qubits) and Bell state
- Visual circuit diagram with qubit wires and gates
- Export to OpenQASM 2.0
- Offline support via service worker
